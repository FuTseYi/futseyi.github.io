A simpler space to build and share

2026-10-26

A short note on the thinking behind this new personal website.

This site is a place to share selected projects, technical experiments, and things I learn along the way.

The homepage is deliberately lightweight: ordinary HTML and CSS, with a small Python build step for Markdown posts. The result is a website that is easy to understand, easy to update, and portable across static hosting services.

What goes here?

  • Selected work in AI, robotics, computer vision, and edge deployment.
  • Practical notes from projects and open-source experiments.
  • Occasional writing about learning and creating.

For deeper technical repositories and ongoing work, see my GitHub profile.

This is a starting point, not a finished story.
