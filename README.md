# FuTseYi — Personal Homepage & Writing

Academic-style personal homepage made from **plain HTML and CSS**, with a separate lightweight Writing section.

- Homepage: `index.html` (no JavaScript framework or scripts).
- Writing: `blog/index.html`, `blog/welcome/index.html`, and `blog/posts.json`.
- Blog source: `content/posts/*.md` (optional automatic Markdown generation when the build workflow is installed).
- Site: https://futseyi.github.io/

The site's public identity is **FuTseYi / Shine**. Keep presentation modest and easy to maintain. Do not add unsupported publications, employers, or awards.

Reference style: [Tianxing Chen's homepage](https://tianxingchen.github.io/), independently implemented without copying third-party source or assets.
